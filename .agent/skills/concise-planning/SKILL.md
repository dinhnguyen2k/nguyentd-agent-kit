# Concise Planning

## Goal

Turn a user request into a **single, actionable plan** with atomic steps.
`.agent/workflows/plan.md` owns Cogain discovery, execution contracts, artifact ownership and dispatch readiness; these modules only help present that plan concisely.
Keep only settled decisions and constraints needed to act; do not produce a second plan/template or require all module headings in the output.
