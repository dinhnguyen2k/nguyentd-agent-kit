# Principle 4: Scripts Are Project-Specific

> 🔴 **DO NOT copy-paste script commands. Choose based on project type.**

| Project Type | Select an existing, verified command |
|--------------|------------------|
| Frontend/React | Target app's lint/typecheck/test or configured browser runner |
| Backend/API | Target service build/test and approved contract validator |
| Mobile | Only when a mobile profile and project exist |
| Database | Migration/test tooling present in the target service |
| Full-stack | Mix of verified commands based on what you touched |

**Wrong:** Copying a script path that is not present in the repository
**Right:** Only scripts relevant to THIS task
