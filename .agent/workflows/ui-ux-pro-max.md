# /ui-ux-pro-max - Premium UI Generator

> **Chế độ**: Premium Visuals (Modern Aesthetic)
> **Yêu cầu BẮT BUỘC**: Clean, Minimalist, High Contrast.

## 🎨 Design Standard

Mọi giao diện được tạo bởi workflow này phải tuân thủ chuẩn thẩm mỹ cao cấp:

1. **Typography**:
   - Sử dụng font chữ hiện đại, rõ ràng, hỗ trợ tiếng Việt đầy đủ.
   - Heading đậm, rõ ràng; Body text thanh thoát, khoảng cách dòng hợp lý (`line-height: 1.5 - 1.6`).
2. **Color Palette**:
   - Sử dụng bảng màu hài hòa, phối màu tinh tế phù hợp với thương hiệu du lịch.
   - Tránh màu quá chói trừ khi dùng làm điểm nhấn (Accent/CTA).
3. **Layout**:
   - Sử dụng CSS Grid / Flexbox chuẩn trong `css/**`.
   - Khoảng trắng (whitespace) rộng rãi, bố cục thoáng đãng.
4. **Micro-interactions**:
   - Hiệu ứng hover mượt mà (`transition: 0.3s ease`).
   - Nút bấm (button) có active/focus state rõ ràng, hỗ trợ truy cập bàn phím.

## 🛠️ Quy trình thực hiện
- **Execution role**: `frontend-specialist` (kiểm định: `verifier`)
1. **Analyze**: Hiểu rõ nhu cầu người dùng và thông điệp trang web.
2. **Structure**: Cấu trúc HTML5 Semantic (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
3. **Style**: Sử dụng CSS Variables cho màu sắc, khoảng cách padding/margin trong `css/**`.
4. **Responsive**: Thiết kế ưu tiên di động (Mobile-first).
